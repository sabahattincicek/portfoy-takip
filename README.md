# Portföy Takip

Kişisel yatırım takip uygulaması: hedef varlık dağılımı, alım kaydı, aylık nominal/reel performans, yeniden dengeleme (rebalancing) ve karşılaştırmalı grafikler.

- Tek dosya (`index.html`), internet ve kurulum gerektirmez.
- Veriler yalnızca kendi tarayıcında (localStorage) saklanır; hiçbir sunucuya gönderilmez. Yedek için **Dışa aktar** (JSON).
- Denemek için `ornek-veri.json` dosyasını **İçe aktar** ile yükleyebilirsin.

Geliştirme geçmişi: [devlog.md](devlog.md)
